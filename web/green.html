Green check: what does this change add that nobody asked for?

Paste a change and the issue it was for. This page lists every dependency the change adds, marks the ones the issue did not ask for (the same rule as Itemator's CI job), then weighs only those: the packages and megabytes each one costs on every fresh install, and what that is in grams of CO2e. How it is worked out

  • Which dependencies: the new-dependency rule of Itemator's rules (v6), the same code the CI job runs, ported to this page; on . It reads requirements files, pyproject.toml and package.json. A dependency is asked for when the issue names it (or, for a whole new package, names the package) or the issue's title names what it implements. A version bump or a move is not a new dependency.
  • From a link: the page asks gitlab.com or api.github.com, without credentials, for the changed files and the text the change is checked against. On GitLab that is the issues the merge request closes, as the CI job reads them. On GitHub it is the issue the pull request's text closes, else the pull request's own title and text. Files the host does not show (too large) are not read, and the page says so.
  • How heavy: the same measure as the weigh page and the card: deps.dev's resolved graph of the pinned version (or today's latest when the line pins none), and each package's download size from PyPI or npm. A size the registry does not give is unknown, never guessed, and the total becomes "at least".
