One line in a manifest. How much comes with it?

When a change adds a dependency its issue did not ask for, Itemator's card says what keeping it costs every fresh install: the packages it brings along and their download size. Try the same measure here, on any PyPI or npm package. This page talks only to deps.dev, PyPI and npm

How it is measured

deps.dev (Google's Open Source Insights) gives the resolved dependency graph of that version. For each package in it, PyPI gives the size of the file pip would most likely download on a Linux x86_64 runner with CPython 3.12, and npm the tarball's length, read from the answer's headers before the download is stopped. Packages bundled inside another are not counted. A size the registry does not give is unknown, never guessed, and the total becomes "at least". The graph is deps.dev's resolution today; an install with a lockfile or on another day can differ. Download bytes are not energy, and this page does not turn them into it.

To weigh only what a change adds beyond its issue, paste the change into the green check.
