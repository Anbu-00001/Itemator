What this page does not do

These three checks read only the lines a change adds, so they work from a diff alone. The others need the project's history and run in the merge request job, where their result goes on the card: files that never changed together, deleted lines a bug fix added, lines that put back what a revert removed, reverts and copies that do not match the commit they cite, a missing change record, the layout-only proof, and opened binary files. A result here is a fact about the added text, not a finding that the change is wrong, and an empty result is not a statement that the change is fine.
