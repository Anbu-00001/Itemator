# Real cases: a reviewer objected, and the rules listed the file

Each row is a file in a public agent pull request (the AIDev dataset) where a human reviewer wrote an inline comment calling it unrelated, out of scope, unnecessary or for a separate pull request, and where Itemator's frozen rules (v6) also list that file as an extra. Comments were picked by keyword, not by reading them; outcomes were read once, on 2026-10-19, under a plan written before the run ([eval/real_catches_rubric.json](../eval/real_catches_rubric.json)).

Of 24 files, 9 were taken out, 7 sat in pull requests closed without merging, and 8 landed with the file. This is not a catch rate: it says nothing about the files reviewers objected to that the rules do not list (most of them, see results/aidev_recall_v6.json), and the reviewers saw no card. "Reading" is one model's reading of the comment, not a person's.
